# Freetime1 — When are you free? Bay Area radio sports planner

Day-by-day free/busy planner for Bay Area AM/FM radio sports (Outer Sunset, SF 94122).
All times Pacific (PT). Coverage 2026–2029.

**Tracked (a minute is FREE only when none are on air):**
MLB (Giants + Athletics HIGH PRIORITY, all 30 clubs shown) · NFL/49ers (49ers HIGH, all 32 shown) ·
Stanford/Cal NCAAF (HIGH) · Westwood One national NFL radio.

**Headline:** Strict (including Spring Training/preseason) there is **no 1/2/3-week all-off window in 2027–2029**
(max 4–5 days in February). Regular-season-only, book **mid-Feb → late Mar** (5–6 weeks).
