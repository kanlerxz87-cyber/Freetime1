Method

  • Clock: America/Los_Angeles (Pacific) for every day boundary.
  • Busy window per game: scheduled start to start + average duration (MLB 158 min, NFL 183 min, college 207 min). See Sources and method.
  • A game with a TBD start uses an estimated start (MLB 1:00 PM day / 7:00 PM night) and is flagged.
  • Free runs require no verified game and no estimated window on any day in the run.
Estimates are labeled. Verify any travel date against the official schedules before booking.
