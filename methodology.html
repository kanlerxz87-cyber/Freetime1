1. Free definition (target rule; not currently certifiable)

A minute would be called FREE only if no tracked game/broadcast were on air and all required schedules and local radio windows were checked. Required scope = MLB (all 30 clubs, Spring Training, regular season, postseason, All-Star/special games; Giants/A’s HIGH), NFL (all games; 49ers HIGH; preseason/postseason), Stanford/Cal football (HIGH), plus Westwood One NFL broadcasts. Current data is incomplete, so no date or interval is certified free. The generated intervals below the dashboard are model output only, not schedule findings.

Busy-day rules (conservative for vacation)

  • MLB spring/regular/postseason: every day busy except All-Star break non-game days (All-Star day itself busy).
  • NFL preseason: Thu–Sun busy. Regular: Sun/Thu/Mon busy (+ Sat Dec–Jan doubleheaders). Postseason: Sat/Sun/Mon busy.
  • NCAAF 2026: actual Stanford/Cal game days only (+ Dec 5 ACC Champ as TBD-busy). Other years: every Saturday in the window (conservative — at least one team likely plays).
  • Westwood One: same primetime/postseason days as NFL (subset; no extra blocking).

3. Estimation rules (no hallucination)

  • If a league has not published a schedule, no matchup, date, or time is invented. The site shows a season window + typical radio window, labeled ESTIMATED.
  • Every table row links its official source. Unconfirmable values are blank + flagged (see Flagged for Review).
  • Full game-by-game slates (2,430 MLB, 272 NFL) are linked, not retyped — retyping 10k rows would guarantee errors.
  • When official schedules publish, update data/schedule.json windows + transcribe anchors, then re-run python3 tools/build_data.py.

4. Time zone

All times Pacific (PT) = America/Los_Angeles (PST in winter, PDT in summer). Westwood One publishes ET; scoreboard converts ET→PT (ET minus 3h). Stanford/Cal publish PT. MLB/NFL league pages publish ET — convert before comparing.
