The schedule is available at MLB's official schedule page. This is a released **regular-season** schedule; it does not make every game/radio detail or postseason date part of the local snapshot. [Release](https://www.mlb.com/orioles/news/mlb-2027-schedule-released) · [Schedule](https://www.mlb.com/schedule/2027-03-23)

Feb. 15–18 is four dates between these two known anchors, **not** a verified all-sports-free week. [Giants schedule](https://www.mlb.com/giants/tickets/spring-training) · [NFL dates](https://operations.nfl.com/calendar-events/nfl-important-dates)
- The direct MLB Stats API schedule endpoint was retrievable through the page-fetch tool during this review. A narrow sample query for 2027-03-25 through 2027-04-10 returned 218 scheduled game records, with game IDs, official dates, game types, teams, venues and UTC ISO kickoff timestamps. This establishes that the official endpoint can be inspected via the fetch tool, not that the whole season has been ingested or independently row-validated. [Sample official API query](https://statsapi.mlb.com/api/v1/schedule/games/?sportId=1&season=2027&startDate=2027-03-25&endDate=2027-04-10&fields=dates,date,games,gamePk,gameDate,officialDate,gameType,teams,away,home,team,name,venue,venue,name,status,detailedState)
