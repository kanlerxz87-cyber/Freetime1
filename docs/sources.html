Sources and method

How free time is calculated

  1. Every tracked game gets a busy window: scheduled start to start + average duration.
  2. Free time is every minute of a Pacific calendar day that no busy window covers (within the day, 12:00 AM to 12:00 AM).
  3. A day with no verified game and no estimated season window is FREE. A day with only estimated windows is ESTIMATED BUSY. A day with a verified game is BUSY.
  4. Free blocks are not claimed for a day when another league is only estimated, because an unverified game could fill the gap.
