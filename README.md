# Free Time Vacation

Bay Area sports vacation screening and a Pacific-time daily scoreboard. View the [GitHub Pages site](https://kanlerxz87-cyber.github.io/Freetime1/).

Run `python3 -m http.server 8000` and open the served root. Tests: `node scripts/test.mjs`. The browser requests the official MLB Stats API for the selected day and adjacent dates; no API key or user data entry is needed. If unavailable, it reports a gap in coverage. The Westwood One snapshot is static, not a syncing affiliate feed. No point in time is labeled verified free under partial coverage. See the dashboard's Flagged for Review section before booking.
